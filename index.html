🔗 GitHub Sync Setup

Your schedule lives on GitHub. Both Jeremy and Sarah connect to the same repository — any change either of you makes syncs automatically.

✖ Not connected
1
Create the GitHub repository

Go to github.com/new. Name it coparent-schedule, set it to Public, and click Create repository.

2
Upload the two files

In the new repo click uploading an existing file. Upload both index.html and data.json from the coparent-repo folder on your Desktop. Commit them.

3
Enable GitHub Pages

In the repo: Settings → Pages → Source: Deploy from branch → Branch: main → / (root) → Save. Your URL will be https://USERNAME.github.io/coparent-schedule

4
Create a Personal Access Token

Go to github.com/settings/tokens/new (classic). Give it a name, set expiration to No expiration, check repo scope, click Generate token. Copy it immediately — you only see it once!

5
Enter your details below and connect

Both Jeremy and Sarah do this once on their own device. You can share the same token.

Changes you or Sarah make will appear within the sync interval you choose above.
